# Swami Vivekanand Academy Website

A modern and responsive school website built using **React.js** to provide information about Swami Vivekanand Academy, including school details, academics, admissions, gallery, and contact information.

## 🌐 Live Demo

https://swami-vivakanand-academy.netlify.app/

## ✨ Features

* Responsive design for all devices
* Modern and user-friendly UI
* School information and introduction
* Academics and admissions sections
* Image gallery
* Contact page
* Fast navigation with React Router

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* React Router DOM

## 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
